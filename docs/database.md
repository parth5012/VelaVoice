# Database Schema Documentation

This document describes the schema of the local SQLite database `models.db` used by the **Vela Voice** application.

## Tables

### 1. `models`
Tracks downloaded translation/cleaner model files on the device.

| Column | Type | Description |
|---|---|---|
| `id` | TEXT (PK) | Unique identifier for the model (e.g. `whisper-tiny-en`). |
| `name` | TEXT | Display name of the model. |
| `url` | TEXT | Download URL for the model binary. |
| `filename` | TEXT | Local filename of the model binary. |
| `expectedHash` | TEXT | Expected SHA-256 hash of the binary file. |
| `path` | TEXT | Absolute local path of the downloaded binary. |
| `status` | TEXT | Download/checksum status (`pending`, `downloading`, `completed`, `failed`). |

### 2. `personal_dictionary`
Stores user word/phrase mappings for pre-processing/cleaning transcriptions.

| Column | Type | Description |
|---|---|---|
| `id` | INTEGER (PK, AI) | Auto-incremented primary key. |
| `original_word` | TEXT (UNIQUE) | Word to match for correction/replacement. |
| `replacement` | TEXT | The replacement text to inject. |
| `language` | TEXT | Optional language code for language-specific mappings. |
| `priority` | INTEGER | Priority weight (default: 1). |

### 3. `dictionary_keywords`
Unique keywords protected from cleaning mutations.

| Column | Type | Description |
|---|---|---|
| `id` | INTEGER (PK, AI) | Auto-incremented primary key. |
| `keyword` | TEXT (UNIQUE) | Protected keyword string. |
| `language` | TEXT | Optional language constraint. |
| `created_at` | DATETIME | Timestamp of entry creation (default: CURRENT_TIMESTAMP). |

### 4. `corrections`
Logs user corrections to transcription strings for analytical modeling and fine-tuning.

| Column | Type | Description |
|---|---|---|
| `id` | INTEGER (PK, AI) | Auto-incremented primary key. |
| `audio_id` | TEXT | Identifier for the transcribed audio file. |
| `original_transcription` | TEXT | Transcription text originally generated by the Whisper engine. |
| `corrected_transcription` | TEXT | Transcription text edited and saved by the user. |
| `edits` | TEXT | JSON array string listing detailed edits (type, original, corrected, position). |
| `edit_distance` | INTEGER | Levenshtein distance between original and corrected texts. |
| `timestamp` | DATETIME | Timestamp when the correction was committed (default: CURRENT_TIMESTAMP). |
| `user_id` | TEXT | Optional user ID of the editor. |
| `confidence_score` | REAL | Optional confidence score of the original Whisper transcript. |
