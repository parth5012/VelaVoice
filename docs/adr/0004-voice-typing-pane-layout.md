Voice Typing Pane Layout

We decided that the Voice Input Method (IME) will use a dedicated recording pane that replaces the keyboard keys when the Voice Input Button is tapped. This pane will contain a Waveform/Visualizer, a "Stop & Clean" button, a "Stop Raw" button, and a "Cancel" button, which avoids layout clutter and provides an intuitive, distraction-free voice capturing interface directly inside the keyboard window.
